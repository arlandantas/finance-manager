# US-102 — Migrar runtime de Node 22 para 26

**Marco:** R4-S · **Deps:** — · **Estimativa:** ≤8 arquivos

## Ler antes (somente estes)
- docs/rules/producao.md
- docs/rules/testing.md

## Objetivo
Produção roda Node 22 (Vercel). Decisão do usuário: versão-alvo Node 26 (LTS desde 2026-10-28), registrada no ADR-044.

## Critérios de aceite (cada um testável automaticamente)
1. AC1: `engines.node` do `package.json`, `.nvmrc` e `Dockerfile` apontam para a versão-alvo decidida.
2. AC2: `@types/node` na mesma major da versão-alvo.
3. AC3: Vercel Project Settings > Node.js Version na versão-alvo (ação do usuário; registrar em `docs/rules/producao.md` §0).
4. AC4: `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm test:int` e `pnpm test:e2e` verdes na nova versão.
5. AC5: smoke de produção (`scripts/smoke-prod.sh`) com `SMOKE OK` após o deploy.
6. AC6: documentação atualizada (`producao.md`, STATE, README se citar Node).

## Fora de escopo
- Atualizar outras dependências sem relação com a compatibilidade com o Node.

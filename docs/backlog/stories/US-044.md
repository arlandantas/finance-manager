# US-044 — Lembrar "dividir" por categoria e revisar no fechamento do mês

**Marco:** R3 · **Deps:** US-043, US-014 · **Estimativa:** ≤8 arquivos (3 pts) · **Bloqueio:** janela de reversão do rateio

## Objetivo
Categorias como Supermercado já nascem divididas, e o mês encerrado avisa sobre despesas "Só meu" para revisar, sem mudar nada sozinho.

## Contrato técnico essencial
- `Category.defaultSplit boolean NOT NULL DEFAULT false` (migração expand); qualquer membro altera por `PATCH /categories/:id { defaultSplit }`; só categorias de despesa (422 `DEFAULT_SPLIT_EXPENSE_ONLY`); com acerto desligado 422 `SETTLEMENT_DISABLED`; arquivar preserva.
- Cliente: hook `useSplitDefaultFromCategory` com estado `{ mode, userPicked }`; categoria com `defaultSplit` e `!userPicked` => `mode = RULE`; escolha manual liga `userPicked`; categoria sem `defaultSplit` não desliga RULE escolhido à mão.
- `GET /settlement/review?period=` => `{ eligible, dismissed, count, totalInCents, items }`; `eligible = settlementEnabled && period.end < hoje`; itens = EXPENSE ativas com `splitMode = NONE`, `competenceOn` no período, sem parcelas, ordenadas `(occurredOn desc, createdAt desc, id desc)`.
- `POST /settlement/review/dismiss` (tabela `settlement_review_dismissals(familyId, periodKey)`, `ON CONFLICT DO NOTHING`; mês em andamento => 422 `PERIOD_NOT_ENDED`).
- "Dividir" na revisão = `PATCH /transactions/:id { version, split: { mode: "RULE" }, confirmSettledPeriod? }` (regra da data do lançamento).

## Critérios de aceite
1. Marcar a categoria "Supermercado" para dividir por padrão mostra "Categoria atualizada"; MEMBER também pode; categoria de receita => 422.
2. Lançar em Supermercado vai para "Pela regra da família"; categorias comuns continuam "Só meu".
3. Escolher "Só meu" manualmente e trocar a categoria não sobrescreve a escolha.
4. Mês encerrado com 2 despesas Só meu (8000 e 4500) mostra "2 despesas Só meu neste mês. Revisar?" e lista os 2 itens; parcelas Só meu não aparecem.
5. "Dividir" um item grava cota 2250 para cada membro; abrir a revisão não escreve nada.
6. "Não perguntar de novo para este mês" dispensa; repetir o dismiss devolve 200 sem duplicar.
7. Mês em andamento não mostra o aviso (`eligible=false`; dismiss => 422).
8. Dividir em mês já acertado exige confirmação (409 `SETTLED_PERIOD_CONFIRMATION_REQUIRED`).
9. Acerto desligado: sem opção nem aviso; review e dismiss => 409.

## Fora de escopo
- Aprender por histórico; regras por descrição; bloquear o fechamento.
